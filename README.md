# 🌈 快乐小牧场

一个面向 5-8 岁儿童的可爱牧场物语网页游戏。**纯 HTML5 + Canvas 实现，零依赖、零构建、零外部素材**（所有角色和场景都是代码绘制的），可以原封不动部署到 GitHub Pages。

## 🎮 在线游玩 / 本地运行

直接把本仓库部署到 GitHub Pages 即可（见下方部署方法），或本地任意静态服务器打开 `index.html`：

```bash
# 任选其一
npx serve .
python3 -m http.server 8000
```

## 🚀 部署到 GitHub Pages（1 分钟）

1. 在 GitHub 新建一个仓库（例如 `my-farm`），把本目录所有文件上传/推送上去：
   ```bash
   git init
   git add .
   git commit -m "🌈 快乐小牧场"
   git branch -M main
   git remote add origin https://github.com/你的用户名/my-farm.git
   git push -u origin main
   ```
2. 打开仓库页面 → **Settings** → **Pages**
3. **Source** 选择 `Deploy from a branch`，**Branch** 选择 `main` / `(root)`，点 **Save**
4. 等 1 分钟，访问 `https://你的用户名.github.io/my-farm/` 就能玩了 🎉

## ⌨️ 操作

- **方向键 / WASD**：走路
- **E / 空格**：做动作（捡、种、浇、挤奶、剪毛、钓鱼、卖东西…走到旁边看提示就行）
- **H**：帮助 ｜ **S**：随时存档 ｜ **Esc**：关闭窗口
- 走到**食槽**旁边按 E 放饲料（商店买饲料，或用玉米代替）—— 连续 3 天不喂，动物会饿跑并停止产出
- 走到**停车架**（小屋旁）按 E：骑上交通工具 / 停下（没车会提示去商店买）

## 📱 手机 / 平板

在手机上打开会自动出现触摸控件：

- 🕹️ **左下角虚拟摇杆**：拖动走路（支持多点触控，可以一边走一边按动作）
- ✋ **右下角动作按钮**：相当于 E 键；钓鱼咬钩时会闪烁提醒
- ❓ 帮助键、🔊 静音键都在屏幕上；点一下游戏画面也能做动作
- 画面自动等比缩放适配屏幕；竖屏时会有「横过来玩」的提示
- 🚫 **已禁止双击放大 / 双指缩放**（`viewport` + 事件拦截双保险），玩的时候不会误触缩放
- 📐 HUD 会跟着画面缩放自动调整大小，语言 / 音乐 / 音效 / 存档按钮在任何屏幕尺寸下都不会跑出画面
- 🖥️ **PC 浏览器上画面始终居中**（用绝对定位 + 回退自身一半来居中，不受窗口比例 / 滚动条 / 100vh 差异影响）
- 🔍 文字、人物、动物都比以前大；物品栏会根据物品数量自动缩放，永远只占一行

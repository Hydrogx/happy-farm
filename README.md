# 🌈 快乐小牧场

一个面向 5-8 岁儿童的可爱牧场物语网页游戏。**纯 HTML5 + Canvas 实现，零依赖、零构建、零外部素材**（所有角色和场景都是代码绘制的），可以原封不动部署到 GitHub Pages。

## 🎮 在线游玩 / 本地运行

直接把本仓库部署到 GitHub Pages 即可（见下方部署方法），或本地任意静态服务器打开 `index.html`：

```bash
# 任选其一
npx serve .
python3 -m http.server 8000
```

## 🚀 部署到 GitHub Pages（1 分钟）

1. 在 GitHub 新建一个仓库（例如 `my-farm`），把本目录所有文件上传/推送上去：
   ```bash
   git init
   git add .
   git commit -m "🌈 快乐小牧场"
   git branch -M main
   git remote add origin https://github.com/你的用户名/my-farm.git
   git push -u origin main
   ```
2. 打开仓库页面 → **Settings** → **Pages**
3. **Source** 选择 `Deploy from a branch`，**Branch** 选择 `main` / `(root)`，点 **Save**
4. 等 1 分钟，访问 `https://你的用户名.github.io/my-farm/` 就能玩了 🎉

```
index.html   # 页面与 UI 结构

game.js      # 游戏逻辑（动物AI、农场、钓鱼、天气、客人、商店、烹饪、纸娃娃）
assets/emoji # 动画 emoji 素材（本地，来自 Noto Emoji Animation）
             #   <codepoint>.webp = 动图（70 个）｜ <codepoint>.png = 静态图（88 个）
assets/verify# 以往修复的验证截图（不是游戏运行需要的东西，可删）
assets/verify/upgrade
             # 本次「设施升级 / 衣帽间 / 宠物房间 / 复数商品找零」的验证截图
             #   map-lv1-*.jpg / map-lv3-*.jpg = 1 级和 3 级的地图（扩建前后对比）
             #   panel-*.jpg = 升级面板（含建筑现状）/ 衣帽间（帽子·头饰·裙子·鞋子）/
             #                 宠物房间与喂食动画 / 找零算式（2 件 · 3 件 · 混合）/
             #                 参观客人（🎫 在农场里看动物）/ 卖货箱（卖一半 + ✕ 离开）
```

> ⚠️ `assets/emoji/` 里的图**是游戏必需资源**，部署/打包时请一起带上。
> 部署在 HTTP 服务下（`http://` 或 `https://`，含 GitHub Pages）动画最完整；
> 如果**直接双击** `index.html` 用 `file://` 打开，浏览器不允许 `fetch` 本地文件，
> 逐帧动画会解不出来——这时地图上的动物会退回「画原图 / 静态图 + 呼吸效果」，
> 商店里的图标仍然会动（`<img>` 标签由浏览器自己播放）。想看到完整动效就起个本地服务：
>
> ```bash
> python3 -m http.server 8000     # 然后打开 http://localhost:8000
> ```

无需任何构建步骤，改完刷新页面即可看到效果。祝小朋友们玩得开心！🐮🥚🌻

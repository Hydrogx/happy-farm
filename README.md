# 🌈 快乐小牧场

一个面向 5-8 岁儿童的可爱牧场物语网页游戏。**纯 HTML5 + Canvas 实现，零依赖、零构建、零外部素材**（所有角色和场景都是代码绘制的），可以原封不动部署到 GitHub Pages。

## 🎮 在线游玩 / 本地运行

直接把本仓库部署到 GitHub Pages 即可（见下方部署方法），或本地任意静态服务器打开 `index.html`：

```bash
# 任选其一
npx serve .
python3 -m http.server 8000
```

## 🚀 部署到 GitHub Pages（1 分钟）

1. 在 GitHub 新建一个仓库（例如 `my-farm`），把本目录所有文件上传/推送上去：
   ```bash
   git init
   git add .
   git commit -m "🌈 快乐小牧场"
   git branch -M main
   git remote add origin https://github.com/你的用户名/my-farm.git
   git push -u origin main
   ```
2. 打开仓库页面 → **Settings** → **Pages**
3. **Source** 选择 `Deploy from a branch`，**Branch** 选择 `main` / `(root)`，点 **Save**
4. 等 1 分钟，访问 `https://你的用户名.github.io/my-farm/` 就能玩了 🎉

| 🐛 已修：地图上的动物像一张不动的贴纸 | 三个原因一起修好了：① 画动物时用 `o.rec.cp` 去找动画帧，可 `rec` 上**从来没存过 `cp`**，于是永远找不到帧，只剩呼吸缩放；② 原来以为「浏览器会自己播放画到 canvas 上的动图」，实测（Chrome）`drawImage` 一张动图 `<img>` **永远只交第一帧** —— 商店里是 `<img>` 标签在播、地图上是 canvas，所以才会「商店会动、地图不动」。现在把 `cp` 存进记录、并且**优先逐帧画**（`ImageDecoder` 拆好的帧），原图直画只作兜底 |
| 🐛 已修：从商店买回来的新动物只有一帧 | 解码重试的定时器会在**解码还在进行时**就把缓存记录删掉重来，于是解码完成时写回一个已经不存在的记录（控制台报 `Cannot set properties of undefined (setting 'src')`），刚解好的 36 帧直接丢掉 → 新买的动物只剩原图第一帧。现在重试只在「确实卡住」时才动手，正在解的一律不打断；解码完成的记录还会做一次存在性检查。另外：**静态 png 不再被反复送进 `ImageDecoder`**（会刷 `Failed to retrieve track metadata.`），失败过的 emoji 会记进 `emojiNoAnim`，不再每帧重试 |
| 🫧 没有 webp 的动物怎么办 | 「谁需要呼吸」不再靠一张手写的 8 个名单，而是**自动判断**（`needsBreath`）：只要这个 emoji **没有逐帧动画**（官方没做，或实测解不出来）就用**静态图 + 呼吸效果**（1.5 秒一个来回、±6% 缩放 + 轻微上下浮动 + 左右轻摆），物品栏里的对应图标用 CSS 动画做同样效果；一旦解码成功就立刻切回真动画。26 种观赏动物里，大象、长颈鹿、斑马、考拉、羊驼这 5 种官方没做动画，就是走这条路 |
| 🐠 水族箱和动物园共用一套动画画法 | 水族箱里的鱼和地图上的观赏动物现在都走**同一个函数 `drawEmojiCreature()`**（sprites.js）：① 有逐帧动画就逐帧画（**水族箱 0.5 倍速**，看着更悠闲；地图上的动物原速）；② 没有动画素材就静态图 + 呼吸；③ 连图都没有才退回文字 emoji。位置语义也统一成「传静止图那一帧的中心」，两条路互相切换不会跳位。**倍速的正确算法**：倍率只作用在「已经过了多少时间」上，即 `(现在时刻 − startedAt) × speed` —— 这样 0.5 就是真的半速、不会倒退也不会定格（实测螃蟹/海豚/金鱼三种都精确 0.498~0.500） |
| 🐛 已修：水族箱的动画比原速还快（说好半速变成了 2 倍速） | 上一版为了让「半速」看起来是往前播，把**传入的时刻**改成了 `t / speed`，等于让动画进度按 `1/speed` 走：speed=0.5 时进度翻倍，实测 **44.3 帧/秒 vs 原速 22**，比原速还快一倍；而且 `at` 和 `startedAt` 不在同一时间基准上，相位还会乱跳。现在把倍率放进相位计算（`emojiFrameIndex(cp, t, speed)` → `(t − startedAt) × speed`），时刻始终传游戏时间，三种海生物实测 0.498 / 0.499 / 0.500，精确半速 |
| 🐛 已修：动物园的动物被画到画面外（变换指数级膨胀） | 抽共用函数时把调用方的缩放（走路/呼吸的 `sc`）包进了 `save/restore`，结果缩放被 restore 抵消、而 `drawZoo` 每帧又再乘一次 → 变换矩阵指数级膨胀，实测涨到 **`4.16e13`**，动物直接被画到画面外（肉眼看就是「动物园的动物不见了」）。现在缩放**留在当前变换里**、由调用方自己的 `restore()` 收尾，实测矩阵稳定在 `a=d=1.2` |
| 🚶 观赏动物的走路 | 25 种观赏动物的走路动作重做过：会有**上下颠 + 轻微前倾 + 起步加速 / 到点减速**，站着时轻轻呼吸，会飞的（蜜蜂、蝴蝶）走的是轻盈的飘。而且**每种动物都按自己图画里头的朝向做了镜像**（头朝左的画风往左走、头朝右的画风往右走），所以**不会出现倒着走**的情况 |
| 📖 动物图鉴 | 图鉴按钮可查看「🦁 动物园」和「🐟 海洋馆」两个列表，动画图标显示收集进度 |

## ⌨️ 操作

- **方向键 / WASD**：走路
- **E / 空格**：做动作（捡、种、浇、挤奶、剪毛、钓鱼、卖东西…走到旁边看提示就行）
- **H**：帮助 ｜ **S**：随时存档 ｜ **Esc**：关闭窗口
- 走到**食槽**旁边按 E 放饲料（商店买饲料，或用玉米代替）—— 连续 3 天不喂，动物会饿跑并停止产出
- 走到**停车架**（小屋旁）按 E：骑上交通工具 / 停下（没车会提示去商店买）
- 走到**任意一栋建筑下方的木牌**按 E：和木牌说话 —— 看这栋建筑现在的状况 + 选升级（地方变大、容量变多）
- 走到**宠物房间门口**按 E：给宠物喂食（花金币）/ 清理便便 / 洗澡 / 领养新宠物
- 走到**衣橱**按 E：进开放式衣帽间换装（帽子 / 头饰 / 裙子 / 上衣 / 裤子 / 鞋子）
